# Team Garra MMA — ¿Quién viene?

A small shared RSVP board for Carlos's MMA group at Duke Gym (Costa Adeje, Tenerife).

Everyone types their name once, then taps "Voy a este" on the sessions they're attending
this week. Everyone sees the same live list — built with Supabase for shared storage,
no login required.

Built as a gift, not a paid job. Static HTML/CSS/JS, deployed on Vercel.
